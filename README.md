## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The frontend consumes the Python Colombia API from `NEXT_PUBLIC_API_BASE_URL`.
If the variable is not defined, it defaults to `http://localhost:8000`.

```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000 npm run dev
```

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Deploy on GitHub Pages

This repository is deployed using GitHub Pages via `.github/workflows/deploy.yml`.

The site is exported statically (`output: "export"`), and the generated files are published from the `dist/` directory.
